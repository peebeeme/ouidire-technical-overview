# Contributing

This repository currently accepts documentation corrections by prior arrangement. Do not submit production code, private prompts, real records, personal information, credentials, or confidential issue reports.

Before proposing a change:

1. use synthetic examples only;
2. distinguish confirmed behaviour from planned work;
3. avoid claims that lack a reproducible evaluation protocol;
4. report security concerns through the private channel specified in `SECURITY.md` once configured.

The production product remains proprietary and is developed in a separate private repository.
